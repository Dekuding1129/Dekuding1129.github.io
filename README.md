# John Gulliver — Portfolio

Personal portfolio for John Gulliver, a creative frontend developer based in the Philippines.

## Featured work

- LOOT — interactive Three.js merchandise storefront
- MIZRACH PINAZ — responsive music homepage
- Ice Cream Invitation — playful single-page experience
- Princess Jane Portfolio — responsive static portfolio

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
npm run lint
```

## Deployment

The `main` branch deploys automatically to GitHub Pages through the workflow in `.github/workflows/deploy-pages.yml`.
